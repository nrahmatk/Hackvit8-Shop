## Description
**Hackvit8 Shop** is a comprehensive website that provides detailed information about the health products offered by our pharmacy. It features a robust Content Management System (CMS) for managing products, categories. The public website includes features like search to enhance user experience, get product by category, cart.

## Key Features
### Public Website
- Filter: Filter products based on various category.
- Search: Search for specific products to quickly find what you’re looking for.
- Add to Cart: Easily add products to your shopping cart.
- Adjust Item in Cart: Modify the quantity or items in your cart.
- Payment: Change order status to paid (dummy).
- Receipt (PDF): Download a PDF receipt.

### CMS (Content Management System)
- Category Management: Add, edit, and delete product categories.
- Product Management: Add, edit, and delete products, including the ability to upload images.
